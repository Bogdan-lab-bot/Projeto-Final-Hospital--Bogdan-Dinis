# Projeto Final - Gestão de Grupo Hospitalar: Bogdan & Dinis

## 1ª Fase - Divisão de tarefas
Analisamos Ambos dividimos as tarefas. O Bogdan foi atríbuido com a inserção de dados nas tabelas INSERT INTO, consultas e fez os CREATE TABLE no script, enquanto o Dinis planeou a criação de base de dados, das tabelas e a atribuição de chaves estrangeiras.

## 2ª Fase - Justificação das decisões de design 
Ambos fizemos decisões de design, o Dinis começou por fazer manualmente as tabelas no DBeaver, adicionando todos os campos necessários, enquanto o Bogdan tinha ficado encarregado de inserir dados. Após a inserção dos dados, o Bogdan foi fazer, pelo script, a criação das tabelas para exprimentar o INSERT INTO já que depois, fica confuso e com bugs quando exporta-se o script das tabelas pelo DBeaver o que impossibilitava de testar tanto os inserts tanto como as tabelas.
